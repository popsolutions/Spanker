# Contributing to Spanker

This repo follows the cooperative governance defined in
[`popsolutions/MAST/GOVERNANCE.md`](https://github.com/popsolutions/MAST/blob/main/GOVERNANCE.md):

- Code contributions reserved for PopSolutions cooperative members
- DCO sign-off (`git commit -s`) mandatory on every commit
- Every PR runs CI (Verilator+cocotb integration when applicable;
  language-specific tests for SW)

See MAST's CONTRIBUTING.md for the full process.
